Architecture & Security Pipeline

Foundational enterprise-grade authentication with Spring Boot 3.4.1, Spring Security 6, JJWT, and PostgreSQL persistence.

Security Architecture Flow
Client Request → CORS Filter → JwtAuthenticationFilter (extracts & validates HS256 Bearer Token) → SecurityContextHolder (sets Principal & GrantedAuthorities) → RBAC Gate (/api/user vs /api/admin) → Controller / Service → Neon PostgreSQL.
Authentication
Stateless HS256 JWT (15-min access) + 30-day dynamic Refresh Token rotation.
Authorization (RBAC)
Granular roles: ROLE_USER and ROLE_ADMIN enforced at filter chain.

Role-Based Access Control (RBAC)

Tests authorization filters against authenticated endpoints.

GET /api/user/profile ROLE_USER or ROLE_ADMIN

Requires valid JWT with standard user authority.

GET /api/admin/dashboard ROLE_ADMIN Only

Standard users will receive 403 Forbidden confirming strict privilege separation.

Dynamic Refresh Token Rotation

Exchanges an active refresh token for a brand new JWT and newly rotated refresh token, invalidating the old token.
